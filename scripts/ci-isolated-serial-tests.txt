# be reproduced on a single local clone that owns its pool). They are NOT
# skipped/weakened: the parallel run `-skip-testing`s them, then a dedicated
# SERIAL pass runs them FULLY and the results are MERGED back into the result
# bundle so the fail-gate counts them. Owner decision after CI runs
# 29805821296 / 29810471358.
#

# fails all retries because retries rerun in the SAME wedged clone process. Two
