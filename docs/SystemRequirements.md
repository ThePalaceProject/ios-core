## Build & quality posture

Engineering policies that are non-negotiable for this project. Many are enforced by hooks (commit/push/PR-create) and pre-PR verification.

### Testing

- **TDD is mandatory.** Production code requires a failing test written first; no fluff tests; mutation testing on changed files.
- **Mutation testing on every PR.** `python3 scripts/mutate.py --file <changed>.swift --tests <tests-dir>/`. Tests must kill at least one mutant per critical-path file.
- **Tautologies and coverage-only tests are banned.** Tests must exercise real behavior, not assert mathematical truths or exist for line coverage alone.
- **Critical paths require airtight coverage.** Sign-in, borrow, download, DRM fulfillment, payment — every branch tested, every error path exercised, every test kills a mutant.
- **Pre-PR verification battery** runs build + tests + lint + coverage + mutation + a11y. Now includes a docs-only fast-path and parallel/scoped test execution (see `scripts/verify-pr.sh`).

### Governance

- **ForgeOS gates are mandatory** before commit/push/PR — `forge_init` → `forge_propose_changeset` → evidence → promote → `forge_release_check: can_release: true`.
- **Hooks block** `git commit` without an open changeset, `git push` without promoted gates, and `gh pr create` without `can_release: true`.

Reference: `docs/Testing/TESTING_POSTURE.md` for the full testing posture, confidence matrix, and known gaps.
