## Detector predicate (canonical text)

- **D2-1 (medium)** `TextField(<short-literal-or-identifier>, text: ...)` / `SecureField(...)` where the label looks like a placeholder (string literal ≤30 chars OR simple identifier), AND no `prompt:` argument, AND no `.accessibilityLabel(` within the 8-line downstream-cure window, AND no `// no-a11y-label:` annotation in the 3-line preceding window.
- **D2-2 (medium)** `Button(action: ..., label: { Text("short-literal") })` (same-line or multi-line opener) with no `.accessibilityLabel` in the downstream-cure window. Multi-line opener requires `Button(` on the `label: {` line itself — explicitly excludes `NavigationLink`/`Link`/`Menu`/etc. so navigation labels (which ARE the right VoiceOver announcement) aren't flagged.

Annotation escape: `// no-a11y-label: <reason>` on a preceding comment line.

Output format (greppable):

```
<file>:<line>: D2-1: medium: SwiftUI TextField with bare-string label / placeholder and no `.accessibilityLabel(...)` or `prompt:` override; default `.placeholderText` reads as disabled — Wall: PP-4421
```

## Notes for integrator

- Detector's `--scan` mode walks a directory recursively and lints every `.swift` file with the same predicate; `--diff` mode parses unified-diff input and lints only added lines per file. Both modes are exercised by the verify-pr.sh / hook wire-ins above.
- The detector deliberately excludes `PalaceTests/`, `Mocks/`, `Preview Content/`, `.forgeos/`, `scripts/_fixtures/`, `scripts/tests/fixtures/`, `.build/`, `Pods/`, `Carthage/` — same exclusion convention as `check-blast-radius.py`.
