## Search with no results renders completely blank screen — no empty-state, no message

Catalog search with no results (e.g. query "zzzzzzzzz") renders a
completely blank screen — no empty-state view, no spinner, no "no results"
message. Indistinguishable from a hung request from the user's perspective.

## Reproduction

**Preconditions:**

- Any library catalog tab active
- Tap the magnifying-glass search icon
- Type a query that returns no results (e.g. 'zzzzzzzzz')
- Submit
